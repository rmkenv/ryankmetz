## SEO Best Practices Implemented

### Meta Tags (Applied to Both Pages)

1. **Essential Meta Tags**
   - `<meta charset="UTF-8">` - Character encoding
   - `<meta name="viewport" content="width=device-width, initial-scale=1.0">` - Mobile responsiveness
   - `<meta name="description" content="...">` - Unique 150-160 character descriptions
   - `<meta name="keywords" content="...">` - Relevant keywords for search
   - `<meta name="author" content="Ryan Kmetz">` - Author identification
   - `<meta name="robots" content="index, follow">` - Search engine crawling instructions

2. **Open Graph Tags (Social Media)**
   - `og:type` - Content type (website)
   - `og:url` - Canonical URL
   - `og:title` - Social media title
   - `og:description` - Social media description

3. **Twitter Card Tags**
   - `twitter:card` - Card type (summary_large_image)
   - `twitter:url` - Page URL
   - `twitter:title` - Twitter-specific title
   - `twitter:description` - Twitter-specific description

### Structured Data (Schema.org)

Implemented JSON-LD structured data for both pages:

**Articles Page:**
- Schema Type: CollectionPage
- Includes: Author information, job title, URL
- Benefits: Helps search engines understand page content and relationships

**GitHub Page:**
- Schema Type: CollectionPage with SoftwareSourceCode items
- Includes: Project names, descriptions, programming languages, repository URLs
- Benefits: Enhanced visibility in developer-focused searches

### Semantic HTML

Both pages use proper semantic HTML5 elements:
- `<header>` - Page header with navigation
- `<nav>` - Navigation menu
- `<main>` - Main content area
- `<section>` - Content sections
- `<article>` - Individual article entries (articles.html)
- `<footer>` - Page footer
- `<h1>`, `<h2>`, `<h3>`, `<h4>` - Proper heading hierarchy

### Accessibility Features

   - Proper heading hierarchy (h1 > h2 > h3 > h4)
   - Semantic HTML elements for screen readers
   - Alt text ready structure (for future images)

2. **Navigation**
   - Clear breadcrumb navigation

3. **Mobile-First Design**
   - Viewport meta tag

### Content Optimization

1. **Title Tags**
   - Under 60 characters
   - Primary keywords at the start
   - Format: "Page Title - Ryan Kmetz | Keywords"
   - Examples:
     - "Articles & Insights - Ryan Kmetz | Climate, Data, Geospatial"
     - "GitHub Projects - Ryan Kmetz | Open Source Climate & Data Tools"

2. **Meta Descriptions**
   - 150-160 characters
   - Include primary keywords naturally
   - Clear call-to-action or value proposition
   - Unique for each page

3. **Heading Structure**
   - H1: Main page title (one per page)
   - H2: Major content sections
   - H3: Individual items/projects
   - H4: Subsections within items

4. **Internal Linking**
   - Breadcrumb navigation
   - Cross-linking between related pages
   - Consistent navigation menu

5. **External Linking**
   - `target="_blank"` for external links
   - `rel="noopener"` for security
   - Links to LinkedIn, GitHub, Substack
