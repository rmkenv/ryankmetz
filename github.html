Energy & Weather Analytics

HDD/CDD Calculator

Language: Python | Status: PyPI Package

A powerful Python library for calculating Heating Degree Days (HDD) and Cooling Degree Days (CDD) using real weather data from the National Weather Service API. Essential for energy management, HVAC optimization, and climate analysis.

Key Features:

  • Calculate HDD and CDD for any location by latitude/longitude
  • Support for custom base temperatures
  • Retrieve degree day data for specific date ranges
  • Simple API with robust error handling
  • Built-in unit tests and type hints for reliability
  • PyPI-ready: pip install hdd-cdd-calculator

Use Cases: Energy management, facilities operations, HVAC analysis, research, weather analytics

Geospatial Analysis & Remote Sensing

Solar Panel Detector (NAIP_PV)

Language: Python | Framework: YOLOv8

A web application that detects solar panels on residential homes using high-resolution aerial imagery. Supports NAIP multispectral imagery and Maryland Six Inch ultra high-res imagery for enhanced rooftop detection accuracy.

Key Features:

  • Upload local images or fetch imagery by drawing bounding boxes on interactive maps
  • YOLOv8 segmentation model trained specifically for solar panels
  • Support for 4-band multispectral imagery including NIR
  • Compute spectral indices: NDVI, NDBI, SPSI, and Solar Photovoltaic Panel Index (SPPI)
  • Automatic area calculation in pixels and square meters
  • Interactive map interface with detection overlays
  • Detection confidence scores and geolocation coordinates

Use Cases: Renewable energy assessment, urban planning, solar adoption mapping, energy audits

Swimming Pool Detection (LAFires)

Language: Python | Platform: openEO

Automated swimming pool detection and analysis using Sentinel-2 satellite imagery and openEO. Features NDWI-based water detection, geolocation, and volume estimation for water management applications.

Key Features:

  • Automated pool detection using Sentinel-2 satellite imagery
  • NDWI (Normalized Difference Water Index) calculation
  • Reverse geocoding to obtain pool addresses
  • Water volume estimation for detected pools
  • Visualization using matplotlib
  • Export results to CSV format

Use Cases: Water resource management, urban planning, drought assessment, municipal water audits
